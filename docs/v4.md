# Workflow Board v4: containers, run overlay, history, layout tools

Everything here is additive; the five existing boards load and validate byte-for-byte unchanged.

## What is new

| Area | What it does | Where |
|---|---|---|
| Card kinds | `container` (a connector such as gmail, drive, calendar, discord) and `note`; optional `pin` and `on_fail` card keys; `group_styles[g].collapsed` | `schema/board.schema.json`, `validate.py` (check_v4), `canvas/js/kinds.js` |
| Connector inventory | Read-only list of each connector's tools, hooks, skills and account; every tool is classified from an allow-list, anything unknown is `blocked` | `adapters/connectors/inventory.py`, `inventory/connectors.json`, `GET /inventory`, `/inventory/{connector}` |
| Container cards | Tool rows with a wire button for allowed tools only; blocked rows show a lock and carry no button, drag handle or `data-cap` | `canvas/js/containers.js` (`window.wbContainers.wire`) |
| Template gallery flags | Modules that reference blocked tools are badged | `library.py`, `GET /templates/touches` |
| Run overlay | Last five runs per card, newest first | `serve_v4_runs.py`, `canvas/js/runs.js`, `GET /runs/{board}?card=` |
| History | Snapshots, diff against current, restore (PUTs through the normal validated `/board/{name}` write) | `canvas/js/history.js`, `GET /history/{board}[/{id}]` |
| Dirty badge | Shows when the board differs semantically from the active (enforced) hash | `canvas/js/dirty.js`, `GET /active` |
| Collapse, tidy, toolbar | Lane collapse with exposed-port chips, edge-layered tidy with undo, toolbar and Alt shortcuts (Alt+T, Alt+Z, Alt+L, Alt+Shift+L) | `canvas/js/collapse.js`, `tidy.js`, `toolbar.js` |
| Module loader | `GET /v4/modules` lists v4 canvas modules on disk; `index.html` imports only those, so a missing module is never a 404 | `serve_v4.py`, `canvas/index.html` |

## Safety properties (tested)

- No send-capable tool is executable. `send_message`, `forward`, `share_file` and non-Discord `reply` are `blocked` in the inventory; `wire()` refuses blocked and unknown tools; blocked rows have no interactive element in the DOM.
- The inventory holds counts and names only, no tokens, ids or message content.
- Restore never touches `boards/active.json`; `executor/` and the five boards are not modified by v4.

## Known limits

- Per-card run overlay depends on the executor emitting card ids (unverified).
